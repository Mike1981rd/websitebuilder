Featured Collection Module - Multiple Selection Implementation

Changes Implemented

✅ Added support for multiple collection selection
✅ Updated modal CSS to fix centering and cutoff issues
✅ Implemented toggleCollectionSelection method
✅ Added visual chips for selected collections
✅ Updated save logic to handle multiple collections
✅ Maintained backward compatibility with single collection format

Data Structure

New format:
config.collections: [1, 2, 3] (array of IDs)
config.collectionNames: ['Collection 1', 'Collection 2', 'Collection 3']
Legacy format (still supported):
config.collection: 1 (single ID)
config.collectionName: 'Collection 1'

UI Changes

  • Collections modal now shows selected collections as blue chips with remove buttons
  • Selected collections are highlighted in the search results
  • Configuration view shows "X collections selected" when multiple are chosen
  • Preview renders properly with multiple collections text
  • Modal is now properly centered using flexbox

Business Logic

Priority: If any products are selected, only products will be shown (collections are ignored)
Collections: If no products are selected, products from all selected collections will be displayed
